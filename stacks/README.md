# Stack packs

Short, opinionated notes per technology: the rules and traps that matter, learned across projects.
A project lists the packs it uses in its `AGENTS.md` (`Stacks: react-vite, node-express, supabase`).
Agents read a pack when they work in that area — not all packs, not every time.

Keep each pack under ~40 lines. Only things an agent would get wrong without being told.
When a project teaches a lesson that applies to the technology (not just the project), add it here.
